Blinks this controller's LEDs for 2 seconds, so you can tell which one this tab is connected to.

Several controllers? Press Disconnect, then Connect and pick another port. Each tab holds one controller, so you can also open one tab per controller.

Output mode

The controller restarts to apply the change. The mode is stored on the controller, so it survives unplugging and firmware updates. In beatoraja and LR2, bind the scratch keys by spinning the turntable in their key config.

Firmware update

Enters update mode without opening the case. When the RP2350 drive appears, copy bitcon.uf2 onto it.
